# Thêm host window server 2022

+ Bước 1: Ta cài đặt Zabbix Agent cho window server 2022. Xem hướng dẫn tại thư mục "configs -> zabbix.md".

+ Bước 2: Tạo host mới cho window server 2022 trên Zabbix. Truy cập và đường dẫn Data collection -> Hosts -> Create host.

<img width="915" height="451" alt="image" src="https://github.com/user-attachments/assets/cdfcff17-9682-4e55-95a9-5c3a386ca4a5" />

+ Bước 3: Cấu hình thống số cho window server 2022, ấn nút “Add”.
<img width="915" height="536" alt="image" src="https://github.com/user-attachments/assets/f146c28c-d66e-47b5-9750-95a3aa15bb37" />

+ Bước 4: Xác nhận đã thêm window server 2022 host thành công. Truy cập đến Monitoring -> Hosts.

<img width="915" height="506" alt="image" src="https://github.com/user-attachments/assets/5083f89f-d7f9-4d67-a569-546216f2d10a" />

# Thêm host pfsense

+ Bước 1: Ta cài đặt SNMP cho pfsense trên zabbix. Xem hướng dẫn tại thư mục "configs -> zabbix.md"

+ Bước 2: Ta tạo host mới cho pfsense trên Zabbix.

Truy cập và đường dẫn Data collection -> Hosts -> Create host.

<img width="773" height="380" alt="image" src="https://github.com/user-attachments/assets/ecabf149-024a-4834-b4b8-4e6a83eb2454" />

+ Bước 3: Cấu hình thống số cho pfsense, ấn nút “Add” để thêm host.

<img width="915" height="643" alt="image" src="https://github.com/user-attachments/assets/b385eb17-8772-47f6-95f1-d78d42c3343e" />
