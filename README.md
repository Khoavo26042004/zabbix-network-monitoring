# Zabbix Network Monitoring & Alerting System

A network monitoring and incident alerting system built with Zabbix,
pfSense, Windows Server and Ubuntu Server.

## Overview

This project was developed as my Bachelor's Graduation Thesis:

"Xây dựng hệ thống giám sát và cảnh báo sự cố mạng sử dụng Zabbix"

The system focuses on monitoring network infrastructure, detecting
service and resource failures, and sending real-time alerts to
administrators.

## Technologies

- Zabbix
- Ubuntu Server 24.04
- pfSense
- Windows Server 2022
- SNMP
- Zabbix Agent
- ICMP
- Telegram Bot
- VMware
- DNS
- Active Directory
